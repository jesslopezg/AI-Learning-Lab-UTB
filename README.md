# AI Learning Lab UTB

Plataforma didáctica para **Aplicaciones de Inteligencia Artificial**. Contiene seis módulos, evaluación de 15 preguntas, simulador de adopción organizacional, tres estudios de caso, tarjetas de estudio, tablero de proyectos y recursos complementarios.

## Despliegue en Vercel

1. En [vercel.com/new](https://vercel.com/new), elige **Import Git Repository**.
2. Selecciona `jesslopezg/AI-Learning-Lab-UTB`.
3. **Framework Preset:** Other; **Root Directory:** `./`; **Build Command:** vacío; **Output Directory:** vacío.
4. Haz clic en **Deploy**. Vercel mostrará la URL oficial del proyecto.

## Ejecución local

Abre `index.html` en un navegador moderno. No requiere dependencias ni proceso de compilación.

## Avisos

- Los datos del tablero y progreso se guardan solamente en localStorage del navegador: no se sincronizan entre usuarios.
- Las fórmulas del simulador son supuestos educativos y **no** estimaciones científicas validadas.
- No existe autenticación, almacenamiento remoto ni integración con un LMS. No introduzcas información confidencial.
- El recurso no depende de grupos, NRC, semestres ni listas de estudiantes.
- Respeta la preferencia del sistema *reducir movimiento*.
